# Voltaiq

> Voltaiq is an enterprise battery intelligence (EBI) software company. Its platform
> automatically collects, cleans and harmonizes data from battery test equipment, production
> lines and fielded systems into a single searchable data core, then extracts electrochemical
> quality indicators, KPIs and traceability for battery R&D, product development, manufacturing
> and in-field applications.

## Agent-relevant summary

- **Public API contract: none.** Voltaiq states it offers "an API that enables flexible custom

  WSDL). Its security page states: "Full technical documentation is available upon request."
- **Deployment shape.** Every customer system runs in its own single-tenant AWS VPC, in a
  customer-selected AWS region. There is no shared API host; no `api.voltaiq.com`,
  `docs.voltaiq.com` or `developer.voltaiq.com` resolves in DNS.
- **No agent surface.** No MCP server, no A2A agent card, no `/llms.txt`, and no served

- **First-party client library.** `voltaiq_studio` (Python), pre-installed inside Voltaiq
  Analytics Studio. Not published to PyPI, npm, or conda-forge; only importable by an
  authenticated user inside their own Voltaiq deployment.
